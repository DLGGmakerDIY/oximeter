# JSON数据绘图工具

这个Python程序可以将ESP32血氧心率监测仪导出的JSON数据文件绘制成交互式图表。

## 安装依赖

在运行程序之前，请先安装所需的依赖：

```bash
pip install -r requirements.txt
```

或者直接安装matplotlib：

```bash
pip install matplotlib
```

## 使用方法

1. **准备JSON文件**
   - 将从网页导出的JSON数据文件（如`20240101_120000.json`）放在 `esp32-web-oximeter/python_draw_json` 目录下
   - 确保JSON文件与 `draw_chart.py` 文件同级

2. **运行程序**

   ```bash
   python3 draw_chart.py
   ```

3. **选择文件**
   - 如果目录下有多个JSON文件，程序会列出所有文件
   - 输入对应的数字选择要绘制的文件

4. **交互操作**
   - **鼠标滚轮**：缩放图表
   - **鼠标拖动**：平移图表
   - **悬停数据点**：查看该点的时间和数值
   - **工具栏按钮**：
     - 🔍 缩放工具
     - 🖱️ 平移工具
     - 📊 数据选择
     - 🔄 重置视图
     - 💾 保存图表（可选）

## 功能说明

- 自动识别同级目录下的所有JSON文件
- 过滤无效数据（BPM或SpO2为-1的数据点）
- 绘制心率和血氧两个子图
- 交互式悬停提示（显示时间和数值）
- 支持缩放和平移
- 显示数据统计信息（平均值、最大值、最小值）
- 图表直接弹窗显示，无需保存

## 数据格式要求

JSON文件应包含以下字段的对象数组：

```json
[
    {
        "millis": 124552,
        "BPM": 75,
        "SpO2": 98,
        "monitoringTime": 124,
        "localTime": 1768628041874
    },
    ...
]
```

## 注意事项

- `-1` 表示无效数据点，程序会自动过滤
- 心率正常范围：30-180 BPM
- 血氧正常范围：80-100 %
- 图表使用监测时间（秒）作为X轴
- 关闭图表窗口后，程序会继续显示数据统计信息
